CxC y comisiones - Venejugos
Panel en línea para compartir con varias direcciones. Viene SIN DATOS: los datos se publican aparte en dataset.json.

Cómo funciona
- cxc.html es el panel visual. Al abrirse lee dataset.json (y claves.json) del repositorio.
- Quien administra carga los Excel en la pestaña Administración y pulsa "Publicar dataset.json".
  Eso escribe dataset.json en el repositorio de GitHub; todos los que abran el panel ven lo nuevo.
- Los demás no necesitan token ni instalar nada: solo abren el enlace.

Archivos (todos sueltos, sin carpetas)
- cxc.html ........ el panel. Va en la raíz del repositorio.
- claves.json ..... las huellas de las claves por empleado (no contiene las claves en sí).
- tasa_bcv.py ..... robot que lee la tasa del BCV (opcional).
- tasa-bcv.yml .... programación del robot. NO se sube arrastrando: se crea como .github/workflows/tasa-bcv.yml
- LEEME.txt ....... estas instrucciones.

Puesta en marcha (una sola vez)
1. Sube cxc.html y claves.json a la raíz del repositorio (Add file > Upload files > Commit changes).
2. Activa GitHub Pages si aún no está: Settings > Pages > Source: Deploy from a branch > main > / (root).
3. Crea el token de acceso (fine-grained):
   https://github.com/settings/personal-access-tokens/new
   - Repository access: Only select repositories > elige el repositorio del panel.
   - Permissions > Repository permissions > Contents: Read and write.
   - Generate token y cópialo (solo se muestra una vez).
4. Abre el panel > pestaña Administración (clave de Administración).
   - Carga el Excel de CxC y el Excel de comisiones.
   - En "Publicar en GitHub" verifica Repositorio, Rama (main) y Ruta (dataset.json), pega el token,
     pulsa "Guardar conexión", luego "Probar conexión" y por último "Publicar dataset.json".
5. Espera 1 o 2 minutos y comparte el enlace del panel:
   https://TU-USUARIO.github.io/TU-REPOSITORIO/cxc.html

Actualizar cada día
- Administración > carga los Excel nuevos > "Publicar dataset.json". El token queda guardado en ese navegador
  (usa "Olvidar token" si es un equipo compartido).

Importante sobre privacidad
- Si el repositorio es público, cualquiera con el enlace puede abrir dataset.json y ver todos los datos
  (clientes, montos, comisiones y cédulas). Las claves por empleado ocultan las comisiones solo en la pantalla:
  NO protegen el archivo dataset.json. Para restringir el acceso hace falta un repositorio privado con
  GitHub Pages privado (plan de pago) u otro tipo de alojamiento con acceso controlado.
- Las claves de los empleados NO van en este paquete ni en el repositorio: están en la lista aparte
  claves-por-vendedor.xlsx. Para agregar un empleado o cambiar una clave hay que actualizar claves.json.

Tasa BCV automática (opcional)
- Sube tasa_bcv.py a la raíz y crea .github/workflows/tasa-bcv.yml con el contenido de tasa-bcv.yml.
- Settings > Actions > General > Workflow permissions > Read and write permissions > Save.
- Actions > "Tasa BCV" > Run workflow. Si no la activas, la tasa se escribe a mano en Administración.
