Conexión GitHub

Sube la CxC y las comisiones al repositorio como un archivo JSON. La vista General (GitHub Pages) lo lee al abrir. Hazlo después de cargar el Excel o guardar cambios.

Token: GitHub → Settings → Developer settings → Fine-grained tokens → solo este repositorio → permiso Contents: Read and write. Hay cédulas y montos de comisión: usa un repositorio privado. Con token configurado, el panel lee y escribe el archivo por la API de GitHub, sin necesitar GitHub Pages. Si el repositorio es público, el JSON también lo es: desmarca "Incluir comisiones" para no exponerlas. En otros dispositivos configura la misma conexión y usa ⟳ Actualizar.
